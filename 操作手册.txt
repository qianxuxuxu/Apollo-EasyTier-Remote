====================================================================
             远程控制一键安装包（Apollo + EasyTier）操作手册
====================================================================

本工具用于 Windows 电脑 + 安卓平板（或手机）异地远程控制：
  - Apollo + Artemis：高清低延迟串流，自动创建匹配平板分辨率的虚拟屏。
  - EasyTier（no_tun = true）：异地 P2P 组网，电脑端不建虚拟网卡，不冲突代理软件。
  - 远程控制中心（RemoteControlUI.exe）：简洁桌面控制台，查看设备、配对码与服务状态。
  - 安装包完全脱敏，部署时会在你的电脑本地随机生成专属网络名称和密钥。

一、文件清单
--------------------------------------------------------------------
  一键下载与部署.bat          双击运行，选择 [2] 一键部署电脑端
  RemoteControlUI.exe         桌面控制台（简洁管理界面，托盘常驻）
  RemoteControlLauncher.exe   桌面快捷启动器
  scripts\deploy_remote.ps1   自动部署脚本
  平板APK安装包\              安卓平板用安装包：
    - app-arm64-release.apk              EasyTier（异地组网）
    - artemis-nonRoot_game-release.apk   Artemis（远程串流）
  操作手册.txt                本手册

二、首次安装步骤（约 5 分钟）
--------------------------------------------------------------------
【第 1 步：部署电脑端】
  1. 将整个文件夹解压到本地（不要在压缩包里直接点运行）。
  2. 双击运行【一键下载与部署.bat】，输入 2 回车（一键全自动部署）：
     - 会弹出一次管理员权限确认框（UAC），点【是】。
     - 默认装到 D:\远程控制（无 D 盘则自动装到 C:\远程控制）。
     - 若直连 GitHub 较慢，可输入加速前缀如 https://ghfast.top/，否则直接回车。
     - 脚本会自动完成：下载并解压 EasyTier -> 随机生成专属密钥（no_tun=true）->
       配置防火墙 5 条规则 -> 设置接电不休眠 -> 注册开机静默自启 ->
       安装桌面控制台并在桌面生成【远程控制中心】快捷方式。
  3. 脚本最后会自动打开 Apollo 图形安装向导：
     - 按提示一路 Next 完成安装即可（安装路径可选 C 盘或 D 盘，控制台都能识别）。
     - 如果不需要用虚拟游戏手柄，建议在组件选择页取消勾选 ViGEmBus（原因见下方避坑 2）。

【第 2 步：初始化 Apollo 后台】
  1. 在电脑打开【远程控制中心】，点右上角外链图标（或浏览器访问 https://localhost:47990）。
  2. 浏览器提示“连接不是私密连接 / 证书风险”属于本地自签名证书，点【高级】->【继续前往】。
  3. 首次进入设置一个 Apollo 管理员账号和密码并登录。

【第 3 步：安装并配置平板端】
  1. 把【平板APK安装包】里的两个 APK 传到安卓平板并安装。
  2. 在电脑打开【远程控制中心】-> 左侧【平板配对】，扫码或复制连接参数。
  3. 打开平板 EasyTier，新建网络填入：
     - 网络名称：电脑上生成的 rc-xxxxxxxx
     - 网络密钥：电脑上生成的 20 位密钥
     - 关闭 DHCP，手动填虚拟 IPv4：10.126.126.2（掩码 24）
     - 公共节点：tcp://225284.xyz:11010（可补充 tcp://easytier.weiai.org.cn:11010）
     点启动后，电脑控制台【全部设备】里出现平板及 P2P 延迟即组网成功。
  4. 安卓 / 澎湃 OS 防杀后台（必做）：
     长按 EasyTier 图标 -> 应用信息 -> 省电策略设为【无限制】+ 开启【自启动】+
     在多任务后台把 EasyTier 卡片【下拉锁定】。

【第 4 步：Artemis 配对电脑】
  1. 打开平板 Artemis -> 点右上角【+】添加主机，输入电脑虚拟 IP：10.126.126.1。
  2. 点击出现的电脑图标，平板会弹出 4 位数字 PIN 码。
  3. 在电脑 Apollo 网页后台点顶部【PIN】-> 切换到【PIN Pairing】标签 ->
     输入 4 位 PIN 码提交即可完成永久配对（注意不要填在默认的 OTP Pairing 里！）。

三、首次配置常见问题与避坑（必看）
--------------------------------------------------------------------
  1. 代理软件图形界面加规则，不要整行粘贴
     - 如果电脑开着 Clash / Mihomo / FlClash 等代理软件（尤其是 TUN 模式），建议把
       EasyTier 和 Apollo 加入直连规则，避免远程流量绕路代理卡顿。
     - 在图形界面「添加规则」弹窗里，不要在「类型=DOMAIN」时把整条
       IP-CIDR,10.126.126.0/24,DIRECT,no-resolve 粘进「内容」框！
     - 要分成 4 条分别添加（置顶）：
         规则 1：类型 PROCESS-NAME  | 内容 easytier-core.exe   | 策略 DIRECT
         规则 2：类型 IP-CIDR       | 内容 10.126.126.0/24     | 策略 DIRECT
         规则 3：类型 PROCESS-NAME  | 内容 apollo.exe          | 策略 DIRECT
         规则 4：类型 PROCESS-NAME  | 内容 sunshine.exe        | 策略 DIRECT
     - 若用 YAML 覆写，直接复制控制台【平板配对】页面底部的 YAML 片段即可。

  2. Apollo 必须走正常图形向导安装，不要强行 /S 静默安装
     - 使用 /S 静默安装会连带触发 ViGEmBus 驱动安装和 Windows PnP 锁，容易导致
       代理软件的 Wintun 虚拟网卡报错断网（需重启电脑才恢复）。
     - 走正常安装向导，不需要虚拟手柄时取消勾选 ViGEmBus 即可避免。

  3. 旧公共节点失效 & 避免开机弹黑框
     - 旧官方节点 tcp://public.easytier.top:11010 已停服，tcp://39.108.52.138:11010
       已不可用（注意：开着代理 TUN 时对不通 IP 测 TCP 延迟可能出现 0~1ms 假通）。
     - 本包已默认配置实测可用的社区节点：
         tcp://225284.xyz:11010
         tcp://easytier.weiai.org.cn:11010
         tcp://183.230.36.171:11010
       后续如节点失效，可在控制台【网络与服务】测速切换，或到以下页面查最新节点：
         https://info.qtet.cn/uptime/easytier
     - 部署脚本已通过系统计划任务静默后台启动 EasyTier（加了 --console-log-level warn），
       不要再手动把 easytier-core.exe 放进开机启动文件夹或注册表 Run，否则每次开机弹黑框。

  4. Apollo 网页配对默认在 OTP Pairing，记得切到 PIN Pairing
     - 打开 Apollo 后台【PIN】页时，默认显示的是【OTP Pairing】，且二维码地址默认是
       art://0.0.0.0:47989。
     - 用 Artemis 4 位数字配对时，点击旁边的【PIN Pairing】标签再输入 PIN 码。
     - 若想用 OTP 扫码，需先手动把 0.0.0.0 改为 10.126.126.1。

  5. 画面发糊、文字发虚或色彩发灰（HDR 泛白）
     - Artemis 默认码率仅 10 Mbps，Apollo 默认 NVENC 预设为 P1，且 Windows 可能自动
       给虚拟屏开启 HDR，导致平板上看起来发糊、发灰。
     - 建议调整：
       * 平板 Artemis：码率调至 25~40 Mbps（同 Wi-Fi 局域网可设 40~80 Mbps）；
         分辨率选平板原生分辨率；编码选 HEVC 或 AV1；看文档/代码可开启 YUV 4:4:4。
       * 电脑 Apollo 后台：Configuration -> NVIDIA NVENC -> Preset 设为 P4 或 P5。
       * Windows 设置 -> 系统 -> 显示：选中虚拟屏，关闭【使用 HDR】。

  6. 笔记本合盖远控 & 杀毒软件误报
     - 笔记本想合盖后继续被控：到 Windows 控制面板 -> 电源选项 -> 选择关闭盖子的功能，
       把【关闭盖子时（接通电源）】设为【不采取任何操作】。
     - 杀毒软件（如火绒 / 360 / Defender）若对无签名的 RemoteControlUI.exe 误报拦截，
       将安装目录（如 D:\远程控制）加入安全软件信任区/白名单即可。

四、日常使用流程
--------------------------------------------------------------------
  - 电脑端：开机自动后台运行 EasyTier、Apollo 和控制台托盘，平时无需手动操作。
  - 平板端：打开 EasyTier 启动 -> 打开 Artemis 点电脑图标连接即可。
    * 外出异地：连虚拟 IP（10.126.126.1）。
    * 在家同 Wi-Fi：也可直接添加电脑局域网 IP，跑满最高画质和码率。
  - 熄灭电脑物理屏：串流进入桌面后按 Win + P 选【仅第二屏幕】，电脑本机屏幕会自动熄灭；
    断开串流后，物理屏幕自动恢复点亮。
