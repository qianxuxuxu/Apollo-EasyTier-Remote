# 远程控制操作手册（Apollo + EasyTier）

本方案用于 **Windows 电脑 + 安卓平板（或手机）** 异地高清低延迟远程控制：
- **Apollo + Artemis**：自动创建匹配平板分辨率的虚拟屏，支持 `Win + P` 熄灭主机物理屏幕。
- **EasyTier（`no_tun = true`）**：电脑端不建虚拟网卡，与 Clash / Mihomo / FlClash 等代理软件 TUN 模式共存。
- **远程控制中心（`RemoteControlUI.exe`）**：极简桌面控制台，管理设备列表、配对二维码、节点测速与后台服务。

---

## 一、首次安装步骤（约 5 分钟）

### 第 1 步：部署电脑端
1. 从 Releases 下载压缩包解压到本地（或 `git clone` 本仓库），**不要在压缩包内直接双击运行**。
2. 双击 **`一键下载与部署.bat`**，输入 `2` 回车（一键全自动部署）：
   - 弹出一次管理员权限确认框（UAC），点击 **【是】**。
   - 默认安装到 `D:\远程控制`（若无独立 D 盘则自动回退至 `C:\远程控制`）。
   - 若直连 GitHub 较慢，可输入加速前缀（如 `https://ghfast.top/`），直连则直接回车。
   - 脚本会自动完成：下载（或编译）控制台与 EasyTier → 在本地随机生成唯一密钥（`no_tun = true`）→ 放行 Windows 防火墙 5 条规则 → 设置接通电源不休眠 → 注册开机静默自启计划任务 → 在桌面创建 `远程控制中心.lnk`。
3. 脚本末尾会自动打开 **Apollo 图形安装向导**：
   - 按默认一直点 `Next` 完成安装即可（装在 C 盘或 D 盘控制台都能识别）。
   - 如果不需要虚拟游戏手柄，建议在组件选择页**取消勾选 `ViGEmBus`**（原因见下方避坑第 2 条）。

### 第 2 步：初始化 Apollo 网页后台
1. 打开桌面 **`远程控制中心`**，点击右上角外链图标（或浏览器访问 `https://localhost:47990`）。
2. 浏览器提示“证书风险 / 不是私密连接”属于本地自签名证书，点击 **【高级】→【继续前往 localhost】**。
3. 首次进入设置一组管理员账号密码并登录。

### 第 3 步：安装并配置安卓平板端
1. 运行 **`一键下载与部署.bat`** 选 `1` 下载安装包，将 `平板APK安装包\` 中的两个 APK 传到平板安装：
   - `app-arm64-release.apk`（EasyTier Android 异地组网）
   - `artemis-nonRoot_game-release.apk`（Artemis 远程串流客户端）
2. 打开电脑 **`远程控制中心`** → 左侧 **【平板配对】**，可直接扫码或复制参数。
3. 打开平板 **EasyTier** 新建网络并填入：
   - **网络名称**：电脑上生成的 `rc-xxxxxxxx`
   - **网络密钥**：电脑上生成的 20 位密钥
   - **虚拟 IPv4**：关闭 DHCP，手动填 `10.126.126.2`（掩码 `24`）
   - **公共节点**：`tcp://225284.xyz:11010`（可补充 `tcp://easytier.weiai.org.cn:11010`）
4. **安卓 / 澎湃 OS 防杀后台（必做）**：
   长按 EasyTier 图标 → 应用信息 → 省电策略设为 **【无限制】**、开启 **【自启动】**，并在多任务后台将卡片 **【下拉锁定】**。

### 第 4 步：Artemis 配对电脑
1. 打开平板 **Artemis** → 点击右上角 **`+`** 添加主机，输入电脑虚拟 IP：**`10.126.126.1`**。
2. 点击添加出来的电脑卡片，平板会弹出 4 位数字 PIN 码。
3. 回到电脑 Apollo 网页后台顶部 **`PIN`** → 切换到 **`PIN Pairing`** 标签页 → 输入平板显示的 4 位 PIN 码提交即可（**注意不要填在默认的 `OTP Pairing` 里**）。

## 二、日常使用流程

- **电脑端**：开机即自动在后台运行 `EasyTier`、`ApolloService` 与控制台托盘，无需任何手动操作。
- **平板端只需 2 步**：
  1. 打开平板 **EasyTier** 确认已连接；
  2. 打开 **Artemis** 直接点电脑图标进入桌面（已配对设备免输 PIN 码）。
- **外网 vs 在家同 Wi-Fi**：
  - 外出 / 不同网络：连接虚拟 IP **`10.126.126.1`**（EasyTier P2P 直连）。
  - 在家同一路由器下：可在 Artemis 额外添加电脑的局域网内网 IP（如 `192.168.x.x`），跑满更高码率与最低延迟。
- **熄灭电脑物理屏**：连入桌面后按 **`Win + P`** → 选 **【仅第二屏幕】**，电脑屏幕立即息屏，断开串流后自动恢复。

## 三、首次配置踩坑与解决方案

### 1. 代理软件图形弹窗加直连规则，不要整行粘贴
开启 Clash / Mihomo / FlClash 等代理（尤其是 TUN 模式）时，在图形界面「添加规则」弹窗中，切勿在「代理类型 = `DOMAIN`」时把整行 `IP-CIDR,10.126.126.0/24,DIRECT,no-resolve` 贴进「内容」框。正确做法是分成 4 条添加并置顶：

| 代理类型 | 内容 | 分流策略 |
| :--- | :--- | :--- |
| `PROCESS-NAME` | `easytier-core.exe` | `DIRECT` |
| `IP-CIDR` | `10.126.126.0/24` | `DIRECT` |
| `PROCESS-NAME` | `apollo.exe` | `DIRECT` |
| `PROCESS-NAME` | `sunshine.exe` | `DIRECT` |

若编辑 YAML 覆写规则，可直接从控制台 **【平板配对】** 页一键复制 YAML 代码片段。

### 2. Apollo 必须走正常图形向导，不要使用 `/S` 静默安装
`/S` 静默参数会同时静默触发 `ViGEmBus` 驱动安装与 Windows PnP 重启锁，容易导致代理软件的 `Wintun` 虚拟网卡报错断网（需重启系统才能恢复）。使用正常图形向导并按需取消勾选 `ViGEmBus` 即可彻底避免。

### 3. 旧公共节点停服 & 禁止直接把命令行加进注册表自启
- 旧官方节点 `tcp://public.easytier.top:11010` 已停服（`NXDomain`）；另外注意开启代理 TUN 时对不通节点测 TCP 延迟可能出现 `1~2 ms` 假通，应以控制台「全部设备」里的真实 P2P 延迟为准。
- 后续若需更换节点，可在控制台 **【网络与服务】** 测速切换，或查看社区实时监控：`https://info.qtet.cn/uptime/easytier`。
- 不要把 `easytier-core.exe` 直接加入 `HKCU\Run`，否则每次开机都会弹出命令行黑框；本工具统一通过系统计划任务 `EasyTier-NoTun-Autostart` 加 `--console-log-level warn` 静默运行。

### 4. Apollo 网页配对默认停在 `OTP Pairing`，记得切换到 `PIN Pairing`
Apollo `PIN` 页默认显示 `OTP Pairing` 且二维码默认地址为 `art://0.0.0.0:47989`。使用 Artemis 4 位数字配对时需点击旁边的 **`PIN Pairing`**；如使用 OTP 扫码，需先点小铅笔将 `0.0.0.0` 改为 `10.126.126.1`。

### 5. 画面发糊或色彩发灰（HDR 泛白）
- **平板 Artemis**：设置中将视频码率从默认 `10 Mbps` 调至 **`25~40 Mbps`**（局域网同 Wi-Fi 可开 `40~80 Mbps`），分辨率设为平板原生，编码优先 `HEVC` 或 `AV1`（看代码/文字可开 `YUV 4:4:4`）。
- **电脑 Apollo 后台**：`Configuration` → `NVIDIA NVENC` → `Preset` 从默认 `1` 改为 **`P4`** 或 **`P5`**。
- **Windows 显示设置**：串流状态下进入「设置 → 系统 → 显示」，关闭虚拟显示器的 **【使用 HDR】**。

### 6. 笔记本合盖远控 & 安全软件误报
- 笔记本需合盖挂机远控时，到「控制面板 → 电源选项 → 选择关闭盖子的功能」，将 **【关闭盖子时（接通电源）】** 设为 **【不采取任何操作】**。
- 无数字签名的本地编译工具若被火绒 / 360 / Defender 误报，请将安装目录（如 `D:\远程控制`）加入信任区/白名单。
